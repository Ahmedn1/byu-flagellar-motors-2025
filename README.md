# BYU — Locating Bacterial Flagellar Motors 2025

A solution to the [BYU - Locating Bacterial Flagellar Motors 2025](https://www.kaggle.com/competitions/byu-locating-bacterial-flagellar-motors-2025) Kaggle competition (cryo-electron tomography landmark detection).

**Final score**: private **0.6069** &middot; public **0.5974** &middot; top of leaderboard was 0.876 / 0.867.

This is below the medal zone, but the codebase + writeup are intentionally publishable: I tracked every experiment and have a clear comparison against the top solutions (see [EXPERIMENTS.md](EXPERIMENTS.md) and the "Comparison vs top solutions" section below).

---

## The problem in two paragraphs

A **tomogram** is a 3D image of bacteria flash-frozen in ice, reconstructed from a tilt-series of 2D projections (cryo-electron tomography). Each tomogram is supplied as a directory of grayscale JPEG slices. The task: given a tomogram, predict the (z, y, x) voxel coordinate of a **flagellar motor** — a ~25 nm molecular machine — if one is present, or abstain (`-1, -1, -1`) if not. About half of the test tomograms contain no motor.

The metric is **F<sub>β=2</sub>** with a **τ = 1000 Å** Euclidean tolerance: a prediction counts as a true positive if it lands within 1000 Å of the ground-truth motor center (in *physical* distance — voxel distance × per-tomogram voxel spacing). β = 2 means recall is weighted ~4× as heavily as precision, so missing a motor hurts more than firing on an empty tomogram.

## The solution

A 2D U-Net (resnet34 encoder from `segmentation_models_pytorch`, 7-channel z-context input) trained with pos-weighted BCE on tomograms resampled to 32 Å/voxel. At inference:

```
test tomogram (JPEG slices)
  → load as uint8 (Z, H, W)
  → resample to 32 Å/voxel
  → 3-way TTA: [identity, h-flip, v-flip] each produces a (Z, H, W) sigmoid heatmap
  → average the three heatmaps in the resampled frame
  → 3D Gaussian smooth (σ=1)
  → global 3D argmax → (z, y, x) in resampled voxels
  → back-transform to original-voxel frame
  → if peak < 0.65 abstain (-1, -1, -1); else emit prediction
```

Both Kaggle T4 GPUs are used in parallel via a thread queue (one model instance per GPU). That's what makes 3-way TTA fit under the 12-hour Kaggle cap.

## Reproducing the submission

Tested on a single A100 40 GB. Should run on smaller GPUs at `batch_size <= 4`.

```bash
# 0. environment
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1. data
#    download the competition data from
#    https://www.kaggle.com/competitions/byu-locating-bacterial-flagellar-motors-2025/data
#    extract so the layout is:
#       data/train/<tomo_id>/slice_*.jpg
#       data/test/<tomo_id>/slice_*.jpg
#       train_labels.csv  (at repo root)

# 2. preprocess to 32 Å/voxel uint8 npy cache (one-time, ~25 GB on disk, ~30 min)
PYTHONPATH=. python scripts/preprocess_all.py

# 3. stratified 80/20 train/val split (one-time)
PYTHONPATH=. python scripts/build_split.py

# 4. train (single A100 ~70 min, 10 epochs)
PYTHONPATH=. python scripts/run_2d.py --cfg configs/recipe.py --exp_dir runs/run0
#    last stdout line is `F_BETA=<val>`. Expect ~0.89.

# 5. trace to TorchScript for Kaggle inference
python submission_assets/build_traced_model.py --ckpt runs/run0/ckpt_best.pt

# 6. upload submission_assets/model_a.ts + model_a.meta.json as a Kaggle Dataset,
#    attach to a notebook on the competition page, paste in
#    notebooks/byu_submission_final.ipynb, Save & Run All, then Submit.
```

## Why this score (and not the top score)

The gap from 0.607 → 0.876 is the sum of compounding choices, not one big miss. From reading the top-4 writeups:

| Choice | Likely Δ F |
|---|---|
| No external data (the top 4 all used Bartley's public dataset of ~1.3k extra tomograms) | ~0.05-0.10 |
| Resampled to 32 Å instead of ~16 Å — saved disk but lost spatial resolution | ~0.05 |
| Per-slice 2D processing instead of 3D-patch sliding window — loses cross-slice context | ~0.05 |
| Fixed threshold instead of quantile thresholding (rank all tomograms by max-peak, drop bottom N%) — solves the CV-vs-LB gap | ~0.03 |
| Single model instead of small ensemble | ~0.02 |
| Light augmentation vs heavy aug (rot90, axis swap, image inversion, brightness gradients, ...) | ~0.02 |

None of these is a magic trick; it's the integral. The biggest single one is the move to a 3D model — gated on having inference budget for it, which the top teams achieved via patch-only sliding window + quantile thresholding + careful TTA budgeting.

## What I tried that didn't work

See [EXPERIMENTS.md](EXPERIMENTS.md) for the full log. Headline list:

- **Weight averaging family** (SWA, EMA, greedy soup) — all within seed noise. Cosine LR decays late-stage checkpoints to nearly-identical points; averaging them doesn't reach a wider minimum. SWALR (PyTorch's purpose-built scheduler) might work but I didn't try after the first three failures.
- **Heavy augmentation** (gamma + intensity + noise + zoom) — hurt val by 0.044 and *also* hurt private by 0.116 in the one submission I burned on it.
- **MixUp** (α=0.2) — softened decision boundaries, FPs nearly doubled.
- **resnet50** — better recall, much worse precision. Net F drop.
- **Multi-task aux head** (presence classifier on encoder bottleneck) — joint loss hard to balance; landed within seed noise even at the right λ.
- **Multi-scale inference** (28 Å + 32 Å) — val F unchanged but FPs cut in half. The smaller-spacing scale made each pass 1.49× more expensive and the submission timed out at 12 h.
- **3D cascade** (route uncertain 2D tomos to a 3D model for second opinion) — submitted, scored 0.385 private. The 3D model's val→private generalization gap was much wider than the 2D model's, so trusting it on the *hardest* cases backfired exactly where we needed it most.

## Comparison vs top solutions

Summarized from the [public writeups](https://www.kaggle.com/competitions/byu-locating-bacterial-flagellar-motors-2025/writeups):

- **1st (Bartley)** — 3D U-Net with ResNet200 encoder, 400-epoch training on heavy GPU augmentations (Mixup, rotations, axis swaps, coarse dropout, color inversion, cutmix). 8-seed ensemble. Quantile thresholding tuned on the public leaderboard.
- **2nd (MIC-DKFZ)** — Built on their nnU-Net framework. EDT (Euclidean Distance Transform) blobs as targets instead of Gaussians. TopK-20% BCE loss. Single model + mirror TTA, no ensemble. 8×A100 for 7 days for the final.
- **3rd (Mimi)** — Ensemble of 5 (3 × 3D backbones + 2 × 2D) at 16 Å spacing. Custom FPN neck for skip-fusion into the stride-16 head. Pseudo-labeled the unlabeled external tomograms. WBF (Weighted Box Fusion) for ensembling.
- **4th (Daddies/Dieter)** — *No decoder at all.* 3D ResNet18 classifier: input 96×160×160 → feature map 512×3×5×5 → flatten to 75 location classes + 1 no-motor class, CE loss. "For this metric (forgiving on localization), drop the decoder entirely." Custom MixUp prevents 2+ motors in a mixed patch.

Universal patterns: 3D models, external data, manual GT corrections, 15.6-16 Å voxel spacing, quantile thresholding, heavy augmentation, sliding-window patch inference.
